## Ce que ton projet devient

Je laisserais même provisoirement de côté le mot *Observatoire*.

On a plutôt :

# **Un baromètre des faits racistes, antisémites et xénophobes médiatisés en France**

La différence avec notre ancienne approche est fondamentale.

**Avant :**

> prendre un énorme corpus → analyser les textes → essayer de détecter quelque chose.

**Maintenant :**

> un fait existe → il est suffisamment notable pour être repris par un ou plusieurs médias → on le documente → on le classe → on suit sa circulation et ses réactions.

C'est beaucoup moins lourd.

## L'unité de base n'est plus l'article

C'est **l'événement**.

Supposons :

- une voiture d'élue dégradée avec des inscriptions racistes ;
- Le Monde en parle ;
- France Bleu en parle ;
- BFMTV en parle ;
- vingt autres sites reprennent l'affaire.

Cela ne donne pas 23 entrées.

Cela donne :

**1 événement**

auquel sont rattachées :

**23 occurrences médiatiques**.

C'est une distinction absolument centrale pour éviter de fabriquer artificiellement une « hausse du racisme » simplement parce qu'une affaire a reçu beaucoup de couverture.

# Ce qu'on enregistrerait

Pour chaque fait, je vois cinq dimensions.

### 1. Le fait

Date, lieu, description factuelle, sources, éventuellement état judiciaire.

### 2. La nature de l'acte

C'est là que vient ta **classification**, sans classement moral.

Par exemple :

- propos / injure ;
- menace / intimidation ;
- discrimination / exclusion ;
- dégradation / vandalisme ;
- violence contre une personne ;
- propagande ou démonstration collective ;
- symbole ou geste nazi / suprémaciste ;
- action ou communication publique discriminatoire.

Cette liste devra être construite à partir d'un **échantillon réel d'affaires**, exactement comme tu le proposes. Je ne la figerais donc pas maintenant.

### 3. Ce ou qui est visé

Autre axe, complètement séparé :

- racisme anti-Noirs ;
- racisme anti-Arabes / Maghrébins ;
- antisémitisme ;
- racisme antimusulman ;
- racisme anti-Roms ;
- xénophobie ;
- etc.

Un événement pourrait avoir plusieurs labels lorsque c'est nécessaire.

### 4. Le contexte

Encore autre chose :

- politique ;
- espace public ;
- sport ;
- média / télévision ;
- école ;
- entreprise ;
- Internet ;
- manifestation ;
- institution publique ;
- etc.

C'est important parce que ton exemple d'un salut nazi dans un stade et celui d'une élue victime de vandalisme peuvent ainsi être comparés **sans prétendre qu'ils appartiennent à la même catégorie d'acte**.

### 5. La circulation

Et seulement ensuite :

- combien de médias l'ont repris ;
- pendant combien de jours ;
- quelles réactions politiques/institutionnelles ;
- éventuellement quelle circulation sur X, YouTube, TikTok, etc. ;
- quel niveau d'engagement observable.

Donc **l'impact médiatique n'entre pas dans la définition du fait**. C'est une deuxième couche.

## Comment le robot travaillerait

Et là, ta conception devient très intéressante.

Il ne faudrait pas demander à une IA :

> « Lis toute la presse française et trouve-moi le racisme. »

On retomberait dans notre ancien problème.

Il faudrait plutôt mettre en place une **veille d'actualité** sur un ensemble de sources médiatiques.

Elle remonte des **événements candidats**.

Par exemple elle trouve :

> Dégradations racistes sur le véhicule d'une élue à Rennes.

Puis le système cherche :

> Cette affaire existe-t-elle déjà dans le baromètre ?

Si oui → il ajoute une source.

Si non → nouvel événement candidat.

Et **un humain valide l'entrée** avant publication.

L'IA devient alors extrêmement utile pour le tri et la déduplication, sans avoir à décider elle-même « ce qui est raciste ».

# Et le baromètre lui-même ?

Je pense que son indicateur principal peut être remarquablement simple :

**nombre d'événements documentés par période.**

Pas un « score de racisme ».

Pas un indice mystérieux.

Pas un degré de gravité.

Par exemple :

**Août 2026 — 18 faits documentés**

puis :

- 6 propos/injures ;
- 4 dégradations ;
- 3 violences ;
- 2 discriminations ;
- 3 manifestations/symboles de haine.

Puis septembre, octobre, novembre...

Et la visualisation permet de descendre jusqu'au fait lui-même.

C'est beaucoup plus défendable.

## La visualisation peut malgré tout devenir très forte

Notre vieille idée de timeline thermique retrouve même ici une vraie utilité.

Chaque événement devient un point ou une marque dans le temps.

Puis tu peux passer de :

**jour → semaine → mois**

et filtrer par :

**type d'acte / cible / contexte / territoire.**

Un pic n'affirme alors rien d'autre que :

> **« davantage d'événements répondant à nos critères ont été documentés pendant cette période ».**

C'est méthodologiquement beaucoup plus propre.

# Le point éditorial qui fera la valeur du projet

Pour moi, ce n'est même pas le comptage.

C'est le fait de pouvoir arriver en mars 2027 et montrer :

> Voici huit mois d'événements documentés, un par un.

Et pouvoir observer :

- leur fréquence ;
- leur nature ;
- les groupes visés ;
- les endroits où ils apparaissent ;
- les espaces où ils se manifestent ;
- les séquences particulièrement chargées ;
- éventuellement leur écho médiatique.

On peut alors commencer à poser des questions sur une éventuelle banalisation **à partir d'un corpus transparent**, plutôt que d'essayer de la démontrer avec un algorithme.

C'est exactement ce qui me semble manquer à notre ancienne approche Assemblée.
